# MFin Tuition Clock · 上课鼓励器

一页可离线使用的课堂计时器，把上课时长换算成已投入的学费。内置 MFin 课程示例，可在「学费与课程」中调整预算、币种、总学分和课时。

![上课鼓励器桌面预览](preview.png)

## 使用

下载或克隆仓库，用现代浏览器打开 `index.html`。页面内嵌样式、脚本与字体，双击文件即可运行。

1. 选课后按「上课」开始。课间可暂停和继续，下课时确认保存。
2. 默认参考时长为 180 分钟。提前下课按实际计时时长计算费用，达到参考时长后继续计时，费用停在本节预算。
3. 标题旁可设置昵称。右上角可进入专注模式，按 Esc 返回。「上课记录」可查看历史及导出 JSON。

昵称、设置和历史保存在当前浏览器。刷新后，正在运行的课堂会按时间戳恢复。不同浏览器或不同网页地址各自保存数据。

## 示例与计算

- 示例预算为 S$75,210，总学分为 48。每门分摊学费等于总学费乘以该课程占总学分的比例。
- 每秒学费等于该课程分摊额除以计划授课总秒数。本节学费按实际计时与参考时长中的较短者计算。
- 第一学期 4 门课、12 学分作为完成示例，补记 S$18,802.50。后续课程的课次和时长为可修改的估算。不同币种分别累计。

示例取自新加坡国立大学 2026 年 8 月的 MFIN 培养说明。金额用于个人学习成本分摊。
